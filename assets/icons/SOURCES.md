# Local catalog icons

All icons are loaded locally by catalog.js from the paths in catalog-data.js. Adjacent names identify the decorative images to screen readers. No external icon service is used.

Sources retrieved 2026-09-29:
- Python: official two-snake SVG, https://www.python.org/community/logos/ and https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg
- C++: official Standard C++ Foundation asset, https://github.com/isocpp/logos/blob/master/cpp_logo.svg
- Cloudflare: cloud symbol extracted without reshaping from the official white horizontal SVG, https://cf-assets.www.cloudflare.com/dzlvafdwdttg/735eoClKJf9XfkqCJs1mfZ/b6767158f39af8d538517df918b8fc2e/logo-white-desktop.svg
- Vercel: official white icon from the download at https://vercel.com/geist/brands
- GitHub: official white Invertocat from https://brand.github.com/GitHub_Logos.zip
- Cursor: official app icon, https://cursor.com/marketing-static/favicon.svg
- Claude Code: Claude brand symbol from Simple Icons, https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/claude.svg (CC0 collection; brand trademarks remain their owners'). Uses Claude orange; this is the Claude family mark, not a separate Claude Code logo.
- Codex: official OpenAI blossom extracted from https://developers.openai.com/codex/ and set to off-white. This is the OpenAI family mark, not a separate Codex logo.
- SQL: original vendor-neutral database cylinder labelled SQL.
- Motion: original neutral movement arrow. The supplied name does not identify a specific product; replace only after the product is confirmed.

Brand names and marks belong to their respective owners. Source shapes are preserved except the documented Cloudflare symbol-only extraction and display fill colors.
